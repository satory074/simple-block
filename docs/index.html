Chrome 拡張 · X (x.com)

Simple Block

X の投稿に「ブロック」ボタンを追加します。
「… → ブロック → 確認」の3手順が、1クリックになります。

ZIP をダウンロード GitHub で見る

特徴

  • 1クリックで即ブロック確認ダイアログなし。ボタンにマウスを乗せると、対象の @ユーザー名 が出ます（リポストなら元の投稿者）。
  • 3秒間は元に戻せる押し間違えても、トーストの「元に戻す」でブロックを解除し、投稿も元の位置に戻ります。
  • ブロックした人の投稿は消えるX 標準のブロックと同じく、タイムラインから隙間なく消えます。あとから読み込まれた投稿も同様です。
  • 小さく、余計な通信なしビルド不要・依存ゼロの数百行。x.com 以外への通信やデータ収集は一切ありません。

インストール

Chrome ウェブストアには公開していないため、手動で読み込みます。

  1. ZIP をダウンロードして展開する
  2. Chrome で chrome://extensions を開く
  3. 右上の「デベロッパーモード」を ON にする
  4. 「パッケージ化されていない拡張機能を読み込む」を押し、展開した simple-block-main フォルダを選ぶ
  5. x.com のタブを再読み込みする

更新するときは、新しい ZIP の中身で同じフォルダを置き換えてから、chrome://extensions でこの拡張の再読み込み（↻）を押してください。

注意

  • ブロックすると相互のフォローが外れます。「元に戻す」でブロックを解除しても、フォローは戻りません。
  • X ではブロックが1日あたり約500件に制限されていて、超えると強制ログアウトされることがあります。1日400件を超えるとトーストで警告します。
  • Web 版 X と同じ内部 API を使っているため、X の仕様変更で動かなくなる可能性があります。ブロックは必ず自分のクリックで1件ずつ行う設計です。
  • 料金はかかりません。
