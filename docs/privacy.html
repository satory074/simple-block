収集する情報

ありません。Simple Block は開発者のサーバーを持たず、利用者の情報を開発者や第三者に送ることはありません。アクセス解析や広告も入っていません。

拡張機能の中で扱う情報

  • x.com の ct0 Cookie（CSRF トークン）: ブロック・ブロック解除のリクエストを x.com に送るときにだけ使います。送り先は x.com だけで、保存はしません。
  • 投稿者の @ユーザー名: ブロックボタンを押した投稿の投稿者を、ブロック対象として x.com に送ります。
  • 当日のブロック件数: 1日の上限（約500件）に近づいたら警告するために、日付と件数だけを chrome.storage.local（お使いの端末内）に保存します。

通信先は x.com だけです。拡張機能を削除すると、保存した件数も消えます。

Chrome ウェブストアのポリシー

Simple Block が扱う情報の利用と移転は、Limited Use（限定的な使用）の要件を含む Chrome Web Store User Data Policy に準拠します。情報はブロックとブロック解除のためだけに使い、販売したり、目的と関係のない用途に使ったりすることはありません。

Privacy Policy (English)

Simple Block does not collect any data. It has no server of its own and sends nothing to the developer or any third party. It contains no analytics or ads.

  • The ct0 cookie (x.com's CSRF token) is read only to send block and unblock requests to x.com. It is sent to x.com only and is never stored.
  • The @handle of a post's author is sent to x.com as the block target when you click the button.
  • Today's date and block count are kept in chrome.storage.local on your device to warn you near X's daily limit. Removing the extension deletes them.

The use and transfer of information handled by Simple Block adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. The information is used only to block and unblock accounts. It is never sold or used for any unrelated purpose.

The extension talks to x.com only. Contact: GitHub Issues.
