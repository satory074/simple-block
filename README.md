# Simple Block

X (x.com) の各投稿に「ブロック」ボタンを追加する Chrome 拡張です。
標準の「… → ブロック → 確認」を **1クリック** にします。

## インストール

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」を ON にする
3. 「パッケージ化されていない拡張機能を読み込む」を押し、この `simple-block` フォルダを選ぶ
4. x.com のタブを再読み込みする

## 使い方

- 投稿の右上（「…」の左）にある **ブロック** ボタンを押すと、確認なしですぐにブロックします
- ボタンにマウスを乗せると、ブロック対象の `@ユーザー名` が表示されます（リポストの場合は元の投稿者）
- ブロックした人の投稿は、X 標準のブロックと同じように画面から消えます
- 画面下のトーストの **元に戻す** を3秒以内に押すと、ブロックを解除して投稿を元に戻します

## 注意

- **ブロックすると相互のフォローが外れます。「元に戻す」でブロックを解除しても、フォローは戻りません。**
- X ではブロックが **1日あたり約500件** に制限されていて、超えると強制ログアウトされることがあります。1日400件を超えるとトーストで警告します。
- X の内部 API（Web 版 X が使っているのと同じ通信）を使っているため、X の仕様変更で動かなくなる可能性があります。自動化ツールとして X の規約上グレーな点もゼロではありません。ブロックは必ず自分のクリックで1件ずつ行う設計です。
- データ収集や、x.com 以外への通信は一切ありません。料金もかかりません。

## 更新方法

ファイルを変更したら `chrome://extensions` でこの拡張の再読み込みボタン（↻）を押し、x.com のタブも再読み込みしてください。
